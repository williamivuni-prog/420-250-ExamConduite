# Exam Conduite

## Description

Exam Conduite est un jeu de course automobile 3D développé avec Unity.  
Le joueur doit parcourir le circuit le plus rapidement possible afin d’améliorer son meilleur temps.  
Notre version ajoute notamment un système de boost, accompagné d’effets visuels, d’un effet sonore et d’une interface affichant l’énergie disponible.  
Le projet est réalisé en équipe dans le cadre des cours de développement Unity et de collaboration.


## Commandes

| Action | Touche |
|---|---|
| Accélérer | W ou flèche vers le haut |
| Freiner/Reculer | S ou flèche vers le bas |
| Tourner | A/D ou flèches gauche/droite |
| Activer le boost | Maj gauche (`Shift`) |
| Frein à main | Espace |
| Pause | Échap |
